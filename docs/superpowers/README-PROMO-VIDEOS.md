## 📋 What You Can Build

### **Tier 1 — Core Stories** (3 videos, highest impact)
- **Guest Ordering Flow:** Scan QR → browse menu → place order (10–13s)
- **Manager Dashboard:** See tables, orders, analytics at a glance (12–15s)
- **Staff Coordination:** Claim, execute, collaborate in real-time (11–14s)

### **Tier 2 — Features** (3 videos, mid-impact)
- **Reservations & Events:** Create, manage, share reservations
- **Happy Hour & Promotions:** Setup specials, drive uptake
- **Analytics & Insights:** View revenue, trends, performance data

### **Tier 3 — Niches** (2 videos, specialized)
- **Floor Map Management:** Design and update venue layout
- **QR Code Tracking:** Generate and scan QR codes

Each scenario includes hook, sequence, pacing, copy, and visual cues.

## 🛠️ Technology Stack

- **Remotion** (video framework)
- **React 19** (components)
- **Tailwind CSS** (styling)
- **Lucide React** (icons)
- **TypeScript** (types)
- **30 fps @ 1080p** (default)
- **Royalty-free music** (Epidemic Sound, YouTube Audio, Pixabay)

**Time per video:** 4–6 hours (research → build → iterate → render)

```
Monday 9am:  Choose Tier 1.1 (Guest Ordering Flow)
             Gather music & screenshots (1 hour)
```

## 🎬 Key Principles

1. **Start with Tier 1** (universal stories, highest ROI)
2. **Full feedback loop** (preview → feedback → iterate → render)
3. **Reuse components** (build once, use many times)
4. **Real data, made-up names** (authentic + private)
5. **Track everything** (PROMO-RENDER-LOG.md keeps you organized)
6. **One video at a time** (4–6 hours per video, not overwhelming)
